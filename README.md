# 🌐 Portfolio & Résumé

Personal portfolio website and LaTeX résumé — showcasing my projects, achievements, and experience as a Computer Engineering student at Shahid Beheshti University.

> 🚀 Live at **[amirgjz.ir](https://amirgjz.ir)** (also mirrored on [GitHub Pages](https://amirgjzh.github.io/Portfolio))

---

## ✨ Features

- **Bilingual & RTL-Ready** — Instant toggle between Persian (RTL) and English (LTR)
- **Zero Frameworks** — Pure HTML5, modern CSS, and lightweight vanilla JavaScript
- **Glassmorphic Design** — Soft gradients, backdrop blur, ambient blobs, and scroll animations
- **Integrated Résumé** — In-browser preview and direct PDF download right from the hero section
- **Responsive & Accessible** — Clean layout on any screen size with `prefers-reduced-motion` support

## 📁 What's Inside

- `index.html` — The single-page portfolio website
- `resume/resume.tex` — LaTeX source code for the résumé
- `resume/resume.pdf` — Pre-compiled résumé PDF
- `images/` — Profile photo, university logo, and contest certificates

## 📄 Building the Résumé

Compile the LaTeX source anytime with:

```bash
cd resume
pdflatex resume.tex
```
